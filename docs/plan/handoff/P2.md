# P2 — Model L3 dan evaluasi v1

Selesai 1 Nov 2026. Evaluasi lokal, tanpa request jaringan. Model tidak dilatih pada halaman web nyata.

## Berkas dan cara menjalankan

- `ml/train.py`: loader komentar, dedup teks ternormalisasi, `GroupShuffleSplit(test_size=0.2, random_state=42)` berdasarkan `group`, lalu tambahan varian obfuskasi 30% positif latih.
- Pipeline: `FunctionTransformer(normalize)` → `TfidfVectorizer(analyzer="char_wb", ngram_range=(2, 5), min_df=2, sublinear_tf=True)` → `CalibratedClassifierCV(LinearSVC(C=0.5, random_state=42), cv=3)`.
- `backend/app/detect/l3_text.py`: `score_text(text: str) -> float`, probabilitas kelas 1; model dimuat sekali secara lazy. Adapter normalisasi batch berada dalam modul backend agar joblib dapat dimuat tanpa mengimpor `ml/`.
- `backend/app/detect/l3_model.joblib`: **1,51 MB**, di bawah batas 50 MB. Penulisan atomik; artefak lama tidak ditimpa jika ukuran melampaui batas.
- `ml/eval_v1.py`: tabel agregat dan skor per halaman; baseline `l3_lite` pada input dan ambang sama.
- `ml/tests/test_l3.py`: cek dedup, pemisahan grup, augmentasi, pemilihan anchor, pipeline, dan lazy loading. Dapat dijalankan tanpa dataset lokal.

```powershell
python ml/train.py
python ml/eval_v1.py
python ml/tests/test_l3.py
python -m pytest ml/tests -q
```

Lingkungan pengukuran: Python 3.14, scikit-learn 1.9.0, pandas 3.0.3. Gunakan versi scikit-learn yang sama saat memuat joblib; artefak lintas versi tidak dijamin kompatibel. `ml/requirements.txt` saat ini mencantumkan scikit-learn 1.9.1, bukan versi lingkungan pengukuran. Dependensi `scikit-learn` dan `joblib` belum tercantum dalam `backend/requirements.txt`; integrasi/deploy sengaja tidak diubah karena batas file tugas. Pemanggil backend masih memakai `l3_lite` sampai integrasi terpisah.

Loader terlebih dahulu menyelesaikan konflik label teks mentah; training membuang konflik label setelah normalisasi dan dedup ulang. `GroupShuffleSplit`: `test_size=0.2`, seed 42; latih 13303, uji 2336. Grup dan teks ternormalisasi terpisah. Holdout Kaggle hanya sumber YouTube pada bagian uji: 2003 komentar. Sumber lain tidak dihitung sebagai Kaggle. Proporsi 20% berlaku pada grup, bukan jumlah baris.

Varian obfuskasi 30% positif hanya ditambahkan sesudah split ke latih: **635 varian**, total latih 13938. Varian yang bertabrakan dengan teks uji dibuang. Uji alexis terpisah: latih ulang semua data komentar non-alexis, bukan model utama; baris yang mengandung `alexis` pada teks mentah atau ternormalisasi dikeluarkan dari latih. Recall dihitung pada 1000 baris positif alexis. Tidak ada halaman web dalam data latih. Generator spam web sintetis belum ditambahkan.

## Verifikasi dan batasan

- `python ml/train.py`: sukses, artefak tersimpan dan ukuran diperiksa.
- `python ml/eval_v1.py`: sukses, semua tabel di atas terukur.
- `python ml/tests/test_l3.py`: lulus.
- `python -m pytest ml/tests -q`: **19 passed, 1 xfailed**. Xfail sudah ada pada suite obfuskasi; peringatan deprecation dari BeautifulSoup/lxml.
- Normalisasi: **37 passed**, dijalankan dengan `--noconftest` karena Python lingkungan utama tidak memiliki SQLAlchemy yang diimpor `backend/tests/conftest.py`. Suite backend penuh tidak dijalankan.
- Muat joblib dari working directory `backend/` dan panggil `score_text` tiga kali: probabilitas valid, cache menunjukkan satu kali pemuatan.
- Model melewatkan `pg_004` meskipun anchor tersembunyi tersedia; domain shift komentar ke anchor web masih nyata. Baseline kata kunci memberi satu positif palsu pada `neg_004`. F1 web baseline sedikit lebih tinggi daripada model, bukan kemenangan model pada semua set.
- Sampel web kecil: tujuh positif hanya dari tiga situs, empat halaman positif berasal dari situs sama. Hasil bukan estimasi generalisasi semua situs.
- Selisih F1 teks asli vs obfuskasi pada set uji: **tidak diukur**.
- Ambang tidak dituning pada set web; model utama tidak dilatih ulang dengan hasil uji web.
